- 100% покрытие alt атрибутами для изображений  
- Семантическая HTML разметка
- Отсутствие критических уязвимостей безопасности

- **Неоптимизированная сборка** - отсутствие минификации

- Оптимизация изображений (WebP, lazy loading)
- Добавление schema.org разметки
